Provenance of the information in this file
------------------------------------------
The configure line below is the "configuration:" string embedded in avcodec-62.dll of the
FFmpeg build used for development (no ffmpeg.exe was available; the local path of the DLL is
omitted here). It is a cross-compiled (x86_64-w64-mingw32), shared build.
The build looks similar to a BtbN "FFmpeg-Builds" win64 GPL shared build (e.g. the
--prefix=/ffbuild/prefix and the library selection). This is an INFERENCE ONLY and is NOT
confirmed. The maintainers have not confirmed who built these DLLs or with which scripts.

       commit b35605ace3ddf7c1a5d67a2eb553f034aef41d55 of https://code.videolan.org/videolan/x264

       matches core 165; it is NOT proven to be the revision that was actually built.
       (Archive URL verified externally on 2026-10-26, 1,040,327 bytes. CI default, overridable
       with the repository variable X264_COMMIT.)
       WARNING: the bundled x264 source may therefore NOT be byte-for-byte the source that was
       compiled into the DLLs. Under the GPL this is a compliance risk. The clean fix is to
       rebuild FFmpeg from known sources and replace the DLLs and this file.
